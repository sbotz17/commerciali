# Entrare con Face ID

- **Parole chiave**: Face ID, riconoscimento facciale, impronta, passkey, accesso, login

Se hai attivato Face ID, nella pagina di accesso trovi il pulsante **Entra con Face ID**: toccalo e conferma con Face ID (o con il codice del telefono). Entri senza scrivere email e password.

## Attivarlo
1. Entra con email e password.
2. Vai in **Impostazioni → Accesso con Face ID**.
3. Tocca **Attiva Face ID** e conferma.

Ogni dispositivo abilitato compare nell'elenco con la data. Per toglierlo, tocca il cestino accanto al nome.

## Da sapere
- Email e password restano sempre disponibili: se Face ID non funziona o lo annulli, entra come sempre.
- Face ID funziona solo sull'indirizzo ufficiale di Closer; su un altro indirizzo il pulsante non compare.
- I dati del tuo viso non vengono mai inviati a Closer: Face ID resta sul dispositivo.
