# Processo — nuovo sviluppo

**Quando leggerlo**: prima di iniziare una funzione nuova.
**Riferimento**: `docs/progetto/squadra-agenti-manuale.md`, `AGENTS.md`.

```
analista → architetto/dba/designer (se serve) → sviluppatori → tester
→ redattore → validatore → validazione Andrea → rilascio
```

- Tester e validatore mai saltabili.
- Il coordinatore non scrive codice.
- Ogni sviluppatore aggiorna il nodo di memoria della sua area.
- Il nuovo sviluppo si ferma in `docs/progetto/da-validare.md` finché Andrea non valida.
