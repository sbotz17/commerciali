# Memoria ad albero — come si aggiorna

- Un nodo = un'area piccola e stabile (una schermata, una collezione, un'integrazione).
- Ogni nodo contiene: quando leggerlo, file coinvolti, punti fermi, flusso, test, ultima revisione.
- Massimo 50 righe per nodo: se serve più spazio, spezza in un sotto-nodo.
- Non copiare codice nei nodi: cita `file:riga` o il nome della funzione.
- Dopo una modifica, aggiorna il nodo interessato e la data.
- Se un nodo non corrisponde più al codice, correggilo subito.
